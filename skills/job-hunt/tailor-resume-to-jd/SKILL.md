# Tailor resume to a job description

Use when Tanzim shares a job posting/JD and wants his resume aimed at it.

Targets: Seattle/remote, $60k+, Coordinator / Asst PM / Ops / Onboarding, startup/mid-size, remote-first. Skip senior/lead/sales/strict-degree roles.

Steps:
1. Pull the JD's must-have keywords (tools, responsibilities, soft skills). List them.
2. Open his base resume (Drive). Reorder/recut bullets so the top third mirrors the JD's top requirements; same nouns the JD uses (ATS matches literally).
3. Quantify every bullet that can be (numbers, %, scope). Cut anything irrelevant to this role.
4. Headline/summary = the exact role title + 1 line of fit.
5. Save as a copy named `Resume_<Company>_<Role>` in the HERMES Drive folder; never overwrite the base.

Pitfalls: don't invent experience; don't keyword-stuff (ATS + humans both read it); keep to 1 page unless he says otherwise.
Verify: every JD must-have appears verbatim somewhere; file is a copy, base untouched.
