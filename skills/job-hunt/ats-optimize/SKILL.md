# ATS optimization pass

Use just before submitting any application.

Steps:
1. Format: single column, standard headings (Experience/Education/Skills), no tables/text-boxes/headers-footers/images — ATS drops those.
2. Keyword coverage: ≥80% of the JD's hard requirements present verbatim. Flag gaps.
3. File: submit `.docx` unless the portal demands PDF; filename `First_Last_Role`.
4. Dates consistent (MMM YYYY), no gaps unexplained.
5. Contact line plain text, no icons.

Pitfalls: fancy templates tank ATS scores; acronyms — include both spelled-out and short form once.
Verify: paste resume into plain text — if it reads cleanly top-to-bottom, ATS will parse it.
