# Veronica Protocol

## Name history
Previously called "A1 Protocol" — renamed by Tanzim on June 4 2026. The Instagram crawler is separately named IG1. Do not confuse the two.

## What it is
Maximum-force deployment. Latest Claude Opus model, highest token budget, subagents enabled. When Veronica is called, no shortcuts, no compression — full capability, full depth.

## When to invoke
- Complex multi-step architectural decisions (TIMBR, FLUXJOB, system design)
- Deep research or analysis requiring sustained reasoning across large context
- High-stakes writing or planning where one pass needs to be right
- Tasks that benefit from parallel subagent execution
- Any task Tanzim explicitly escalates to Veronica

## Model config
- **Model**: Latest Claude Opus available at time of invocation — always most recent
- **Max tokens**: Maximum available — full context window, 4,000+ output tokens
- **Subagents**: Enabled — deploy parallel agents where tasks can be split
- **Extended thinking**: Enable where multi-step reasoning benefits the task
- **Temperature**: Default (1.0) unless precision required (0.2–0.5)

## How to deploy
When Tanzim says "Veronica" or "Veronica protocol":
1. Confirm in one line: *"Veronica engaged."*
2. Switch to latest Opus
3. Enable subagent deployment if task warrants parallel execution
4. Run at full depth — do not compress or shortcut
5. Report back with full output
