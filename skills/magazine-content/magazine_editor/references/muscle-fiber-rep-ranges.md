# Muscle Fiber Type → Rep Range + Set Volume (Hypertrophy Focus)

Built for TIMBR 4-week workout program. Every program uses these as the locked template.
Source: sports science consensus on fiber type distribution + hypertrophy-optimised rep ranges.

## The Framework

Slow-twitch (Type I) fibers: fatigue-resistant, respond to higher reps (15-25)
Fast-twitch (Type II) fibers: powerful, fatigue quickly, respond to lower reps (6-10)
Mixed muscles: middle range (10-15)

Hypertrophy is maximised by matching rep range to dominant fiber type.

## Application to TIMBR Program Template

### Upper Day Exercise Count
Big muscles (chest, back): 3 exercises each
Small muscles (biceps, triceps, shoulders): 2 exercises each

### Lower Day Exercise Count
Big muscles (quads, hamstrings, glutes): 3 exercises each
Small muscles (calves, abs): 2 exercises each

### Rep Range Application (example Upper Day)
- Chest press: 8–12 reps (mixed fiber)
- Lat pulldown: 8–12 reps (mixed fiber)
- Lateral raise: 10–15 reps (medial delt, mixed)
- Bicep curl: 8–12 reps (slight fast-twitch)
- Tricep pushdown: 6–10 reps (fast-twitch dominant)

---

## Progressive Overload by Week

| Week | Application |
|---|---|
| 1 (Baseline) | Use base rep range, moderate load, establish form |
| 2 (Volume) | Add 1 set per exercise OR add 2 reps at same weight |
| 3 (Intensity) | Increase load 5-10%, stay within rep range |
| 4 (Deload) | Drop to 60% of Week 3 load, reduce sets by 1, same rep range |

---

## Notes
- Soleus and abs almost always go to the higher end of their range — these muscles are built for endurance
- Hamstrings and triceps almost always sit at the lower end — fast-twitch dominant, respond to heavier loads
- When in doubt on a mixed muscle, default to 10–12 reps — widest hypertrophy evidence base
- Gastrocnemius and soleus should be trained separately where possible — different fiber profiles, different rep ranges
