# HERMES Drive conventions

Use for any Drive file create/move/share for Tanzim.

Conventions:
- Work products live in the HERMES Drive folder (job docs, MAGPROD, trackers).
- Naming: descriptive + entity + date where relevant (`Resume_<Co>_<Role>`, `Issue_<NN>_<Month>`).
- Sharing: least privilege; never world-readable; grant edit only to the asset owner.
- Copies, not overwrites, for anything templated (resumes, blueprints).

Pitfalls: never broaden sharing without explicit ok; don't expose folder IDs in chat/skills; keep originals.
Verify: file in HERMES folder, named to convention, shared minimally.
