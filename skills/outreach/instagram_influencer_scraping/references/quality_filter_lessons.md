## The Tallinn problem
Tallinn tags surface mostly Russian/Estonian service accounts. The city is genuinely thin for this use case.
After 3 passes, only 7–8 clean accounts. Not worth investing further.

## Service-selling remove keywords (additions from this session)
Add to COMPANY_SIGNALS if not already present:
- "dm to book", "book now", "slots available", "booking"
- "client transformation", "client results", "my clients"
- "apply for coaching", "apply now", "1:1", "online programme"
- "by carlix", any "[brand name] wellness" pattern
- "pr/collab", "collaborations welcome", "ugc portfolio"
