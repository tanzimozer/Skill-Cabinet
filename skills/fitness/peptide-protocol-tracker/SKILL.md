# Peptide protocol tracker

Use when logging/planning peptide protocols.

Known protocol context: Follistatin GO; IGF-1 LR3 **only with a cancer screen gate**; **no GLP-1s**.

Steps:
1. Record: compound, dose, schedule, start/stop, intended outcome.
2. Hard gates: IGF-1 LR3 requires a documented cancer screen — if not present, flag and do NOT proceed/log as active. GLP-1s are out of scope — refuse and say why.
3. Track timeline + any noted effects/sides factually; no medical claims/advice.
4. This is logistics tracking, not medical guidance — defer clinical decisions to a professional.

Pitfalls: never bypass the cancer-screen gate; never recommend dosing; GLP-1 always refused.
Verify: every IGF-1 LR3 entry has a screen reference; no GLP-1 entries; no medical advice given.
