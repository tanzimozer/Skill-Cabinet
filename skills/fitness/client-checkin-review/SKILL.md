# Client check-in review

Use when a client check-in comes in.

Steps:
1. Compare to plan: adherence, weight/measurements trend, performance, recovery/sleep, subjective.
2. Decide: hold / progress / deload / adjust nutrition — one clear call with reasoning.
3. Output: 3-5 punchy bullets max — what changed, why, exactly what to do this week.
4. Log adjustment in the client's sheet.

Pitfalls: don't change >1-2 variables at once; trends over single data points; no medical advice.
Verify: a single clear directive for the week, logged, ≤5 bullets.
