# Training split builder

Use when the ask is specifically the split structure.

Steps:
1. Inputs: days/week available, goal (strength/hypertrophy/recomp), recovery capacity, weak points.
2. Choose split: 3d full-body, 4d upper/lower, 5-6d PPL — match to days + recovery, not preference.
3. Set weekly volume per muscle in the productive range; sequence to protect priorities/weak points early in the week.
4. Hand off to program-design skill for full periodization if needed.

Pitfalls: more days ≠ better — match recovery; don't exceed sane weekly volume; weak points trained fresh.
Verify: split fits the stated day count and leaves recovery; priorities sequenced early.
