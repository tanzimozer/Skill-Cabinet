# New magazine issue

Use when Tanzim says start/spin up a new issue.

MAGPROD_ENGINE lives in the HERMES Drive folder, subfolders: blueprints/, issues/, trainers/, backups/.

Steps:
1. In issues/, create `Issue_<NN>_<Month>`.
2. Copy the current blueprint from blueprints/ into it as the working doc.
3. Create an issue checklist (sections, owners, deadlines).
4. Note the issue in MEMORY only as a durable fact if it's an ongoing reference (issue number, month) — never paths.

Pitfalls: never edit the blueprint master — always copy; keep everything inside the issues/ subfolder.
Verify: new issue folder exists with a blueprint copy + checklist; blueprint master unchanged.
