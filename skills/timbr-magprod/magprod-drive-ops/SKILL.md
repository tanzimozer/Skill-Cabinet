# MAGPROD Drive operations

Use for MAGPROD file moves/renames/sharing.

Conventions:
- Everything under the HERMES Drive folder; MAGPROD subfolders blueprints/ issues/ trainers/ backups/.
- Naming: `Issue_<NN>_<Month>`, `Trainer_<Name>_<Asset>`, `Blueprint_v<N>`.
- Sharing: least-privilege; only grant edit to people who own that asset.

Steps: confirm the target subfolder → apply the naming convention → set sharing to match the owner → log nothing sensitive to memory.

Pitfalls: never move the blueprint master out of blueprints/; never broaden sharing without Tanzim's ok.
Verify: file is in the right subfolder, named to convention, shared minimally.
