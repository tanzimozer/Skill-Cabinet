# Trainer asset intake

Use when trainer material comes in (often via Towsif).

Steps:
1. Validate: right format, complete, correct trainer attribution, usable quality.
2. File into trainers/ as `Trainer_<Name>_<Asset>_<Date>`.
3. Log it in the issue checklist as received; flag anything incomplete back to the submitter (or Towsif).
4. Don't edit the asset's substance — intake only.

Pitfalls: never lose attribution; incomplete assets get flagged, not silently filed; keep originals.
Verify: asset in trainers/ with correct name + logged; gaps flagged to submitter.
