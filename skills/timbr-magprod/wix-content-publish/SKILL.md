# Wix content publish (TIMBR)

Use when final content is ready for the TIMBR Wix site.

TIMBR = Wix site selling Blair/Shumon/Taylor content; Sagar runs the MVP.

Steps:
1. Confirm content is final-approved (not draft) and which creator it's under.
2. Stage it in Wix (correct collection/page for that creator).
3. Preview before publish; check media renders, links, pricing if applicable.
4. Publish; record what went live + date in the issue/content tracker.
5. If MVP-related, coordinate with Sagar rather than overriding.

Pitfalls: never publish unreviewed/draft content; don't touch MVP areas Sagar owns without checking; verify creator attribution.
Verify: live page matches the approved content; preview checked before publish.
